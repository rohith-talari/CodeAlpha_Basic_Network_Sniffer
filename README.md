# Basic Network Sniffer

This project was developed as part of the CodeAlpha Cyber Security Internship.

The main goal of this project is to capture and analyze network packets using Python and Scapy. It helps in understanding how packets move through a network and how protocols work.

## Features
- Captures live network packets
- Detects TCP, UDP and ICMP protocols
- Displays source and destination IP addresses
- Shows port information
- Displays packet payload preview
- Saves logs into a file

## Technologies Used
- Python
- Scapy

## How to Run

Install Scapy:

pip install scapy

Run the program:

python sniffer.py

## Sample Output

- Source IP
- Destination IP
- Protocol Type
- Ports
- Payload Data
